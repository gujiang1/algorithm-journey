# algorithm-journey 算法学习之旅

24周从零开始学算法，目标：算法工程师


##学习计划
|阶段|周次|内容|
|---|---|---|
|一|1-4周|Python基础、数据结构与算法、数学基础|
|二|5-8周|机器学习、特征工程、竞赛实战|
|三|9-12周|PyTorth、CNN/Transformer、大模型微调


##目录

- `01_python基础/` — Python 语法练习与实用脚本
- `练习1-批量整理文件.py` 按扩展名批量重命名文件（带预览模式）
- `练习2-CSV统计分析.py` 读取 CSV 完成统计与筛选并导出报告
- `练习3-JSON转表格.py` 把嵌套 JSON 拍平成表格导出 CSV
